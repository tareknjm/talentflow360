## Avant chaque répétition

1. Vérifier TFDev et le type d'org ; contrôler la version du code et celle de l'agent.
2. Relire les résultats réels : ne pas présenter comme terminée une fonction NotRun ou Blocked.
3. Exécuter le reset exact du lot de démonstration selon setup.md, puis vérifier les effectifs.
4. Vérifier l'accès du recruteur et du RH ; éviter toute page contenant l'identité dans le contexte du chat.
5. Choisir un créneau encore futur dans l'org et vérifier l'absence d'envoi externe.
